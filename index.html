How GitShare.ch Works

GitShare.ch is a free, open-source tool that generates beautiful social media screenshots from any public GitHub repository. Enter a repository URL or owner/repo slug, and GitShare fetches the metadata from the GitHub API to build a customizable screenshot with the repo name, description, stars, forks, language, license, and more.

Features

  • Generate shareable screenshots from any public GitHub repository
  • Choose from preset dimensions for Twitter (X), Facebook, Instagram, LinkedIn, and TikTok
  • Customize background colors, gradients, or upload a background image
  • Light and dark theme options
  • Export as PNG, JPEG, or WebP
  • Add your own branding logo with adjustable size, opacity, and position
  • Toggle individual stats: stars, forks, language, license, open issues, contributors
  • No login, no account, no backend — runs entirely in your browser

Supported Platforms

GitShare.ch includes dimension presets optimized for every major platform: X (Twitter) landscape, square, and vertical; Facebook feed and stories; Instagram feed, square, vertical, and stories; LinkedIn feed and square; and TikTok landscape, square, vertical, and stories formats.
